## Design system

- Palette: `#080808`, `#111111`, `#E50914`, `#8F0008`, `#FFFFFF`, `#B8B8B8`
- Display type: DejaVu Sans Bold
- Technical type: Noto Sans Mono
- Shared language: thin technical grid, one-pixel frames, restrained red signals, dark UI modules, generous negative space

Import the six self-contained SVG files from `canva/` into one Canva project and keep the page names above. The SVGs preserve vector text, frames, dividers, and accents, with each technical plate embedded inside its file so no external image link is required.
